🔧 Developer Stack

POST /v1/tts

Generate Cantonese speech

{
  "text": "你好，呢度係廣東話",
  "voice": "zh-HK-HiuMaanNeural",
  "format": "ogg"
}

→ Returns: audio file (MP3/OGG Opus)


POST /v1/image

Generate AI images

{
  "prompt": "cyberpunk city at sunset",
  "model": "flux",
  "width": 1024,
  "height": 1024
}

→ Returns: PNG image (1024×1024)

⚠️ Cost Reality

Why We're Free / $0 API Cost

Our TTS runs on Microsoft Edge TTS (free, no API key). Our images run on Pollinations.ai (free, no API key). This means zero marginal cost per request — we pass the savings to you in the free tier. We've validated this stack works end-to-end (sent Cantonese voice to Telegram as a voice message, generated 23 free images across 5 models).

The catch: lower rate limits than paid APIs, no SLA on free tier. Upgrade for production use.
