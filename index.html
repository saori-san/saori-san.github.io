🔧 Developer Stack

POST /v1/tts

Generate Cantonese speech

{
  "text": "你好，呢度係廣東話",
  "voice": "zh-HK-HiuMaanNeural",
  "format": "ogg",
  "jyutping": false
}

→ Returns: audio file (MP3/OGG Opus)
POST /v1/tts/clone

Voice cloning (Pro+)

{
  "text": "你好，我係你嘅聲音",
  "voice_sample": "base64_audio...",
  "format": "ogg"
}

→ Returns: cloned voice audio
POST /v1/image

Generate AI images (5 models)

{
  "prompt": "cyberpunk city at sunset",
  "model": "flux",
  "width": 1024,
  "height": 1024
}

→ Returns: PNG image (1024×1024)
